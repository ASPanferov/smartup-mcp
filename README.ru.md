# SmartUp MCP

**[English](README.md) · [Русский](README.ru.md) · [O'zbekcha](README.uz.md)**

[MCP](https://modelcontextprotocol.io)-сервер для **SmartUp ERP**. Даёт AI-ассистенту читать заказы, остатки, цены, контрагентов, оплаты и долги из вашей учётной системы — а если вы разрешите, то и создавать заказы и менять их.

Работает с Claude Desktop, Claude Code, OpenAI Codex, OpenClaw, Hermes и любым другим MCP-клиентом.

```
Вы:  Кто нам должен и кому звонить первым?
AI:  [smartup_debt] → 8 клиентов с долгом, всего 18,2 млн сум.
     Yapona Mama — 6,9 млн, отгрузка в июле, оплат с тех пор не было.
     Jononchicken — 8,1 млн, но у него ещё 13,5 млн заказов в работе.
     Позвонить до того, как отгружать дальше.
```

## Что умеет

**17 инструментов в трёх группах.**

### Чтение

| Инструмент | На что отвечает |
|---|---|
| `smartup_orders` | Заказы за период, с составом и статусами |
| `smartup_order` | Один заказ целиком по номеру сделки или внешнему номеру |
| `smartup_stock` | Свободные остатки по товарам и складам, с названиями |
| `smartup_products` | Номенклатура: название, код, артикул, упаковка |
| `smartup_prices` | Цены по типам прайса |
| `smartup_contractors` | Юрлица и их торговые точки |
| `smartup_payments` | Приходы денег за период |
| `smartup_returns` | Возвраты за период |
| `smartup_reference` | Склады, группы товаров, производители, типы цен, договоры, рейсы |
| `smartup_export` | Прямой вызов любого метода `$export`, когда готового инструмента мало |
| `smartup_usage` | Сколько запросов коннектор потратил сегодня |

### Сводки

Готовых методов под них в API нет. Каждая — это две-три выгрузки и арифметика поверх.

| Инструмент | На что отвечает |
|---|---|
| `smartup_debt` | Кто сколько должен: отгружено − оплачено − возвраты, по каждому клиенту |
| `smartup_sales` | Продажи в разрезе клиентов, товаров, дней или статусов, с долями |

### Запись — по умолчанию выключена

| Инструмент | Что делает |
|---|---|
| `smartup_order_create` | Создаёт заказ, по умолчанию черновиком |
| `smartup_order_status` | Меняет статус: провести, отменить, двинуть дальше по этапам |
| `smartup_order_note` | Пишет примечание в шапку заказа |
| `smartup_contractor_create` | Заводит юрлицо или торговую точку сети |

## Безопасность

Писать в живую учётную систему — не то же самое, что читать из неё. Три правила делают эту разницу явной.

**Запись выключена, пока вы её не включите.** По умолчанию коннектор только читает. Инструменты записи при этом видны — чтобы ассистент отвечал «это запрещено в настройках», а не «я не умею», — но вызов отклоняется до обращения к сети.

**Запись идёт ровно в один филиал.** Когда режим включён, коннектор принимает только запросы, адресованные тому филиалу, код которого стоит в настройках. Запрос без филиала отклоняется тоже: SmartUp выполняет такой запрос по организации **по умолчанию**, а это чаще всего боевой контур.

**Заказы создаются черновиком.** Пока вы не назовёте статус явно, новый заказ уходит со статусом `D`: менеджер его видит, склад — нет. У каждой записи есть ключ идемпотентности, поэтому повтор после обрыва связи обновит тот же документ, а не создаст второй.

**Суточные квоты общие с боевой работой.** SmartUp ограничивает число вызовов в сутки — около сотни для справочников, несколько сотен для документов, — и это те же лимиты, которыми живёт отгрузка. Коннектор считает свои вызовы, останавливается заранее и держит справочники в кэше шесть часов. Текущий расход показывает `smartup_usage`.

## Установка

### Claude Desktop — в одно движение

Скачайте `smartup.mcpb` из раздела [Releases](https://github.com/ASPanferov/smartup-mcp/releases) и перетащите в окно Claude Desktop. Можно вместо этого дважды кликнуть по файлу или пройти **Настройки → Расширения → Дополнительно → Установить расширение**.

Дальше Claude сам спросит настройки:

| Поле | Что означает |
|---|---|
| **Логин** | Пользователь SmartUp, от имени которого работает коннектор |
| **Пароль** | Хранится в системном хранилище ключей, а не в файле |
| **Код филиала** | Филиал по умолчанию, например `220.012`. Для записи обязателен |
| **Разрешить изменение данных** | По умолчанию выключено. Включайте, только если хотите, чтобы ассистент создавал заказы |
| **Адрес сервера** | `https://smartup.online`, если ваш SmartUp живёт не на другом адресе |
| **Предел запросов в сутки** | По умолчанию 60 |

### Любой другой клиент — из исходников

```bash
git clone https://github.com/ASPanferov/smartup-mcp.git
cd smartup-mcp
npm install
```

Дальше укажите клиенту путь к `server/index.js`, а доступы передайте через переменные окружения:

| Переменная | Обязательна | По умолчанию |
|---|---|---|
| `SMARTUP_LOGIN` | да | — |
| `SMARTUP_PASSWORD` | да | — |
| `SMARTUP_FILIAL_CODE` | для записи | — |
| `SMARTUP_ALLOW_WRITE` | нет | `false` |
| `SMARTUP_BASE_URL` | нет | `https://smartup.online` |
| `SMARTUP_DAILY_BUDGET` | нет | `60` |

## Подключение

### Claude Code

```bash
claude mcp add smartup \
  --env SMARTUP_LOGIN=ваш_логин \
  --env SMARTUP_PASSWORD=ваш_пароль \
  --env SMARTUP_FILIAL_CODE=220.012 \
  -- node /абсолютный/путь/smartup-mcp/server/index.js
```

Либо положите в проект `.mcp.json`, оставив секреты в окружении:

```json
{
  "mcpServers": {
    "smartup": {
      "command": "node",
      "args": ["/абсолютный/путь/smartup-mcp/server/index.js"],
      "env": {
        "SMARTUP_LOGIN": "${SMARTUP_LOGIN}",
        "SMARTUP_PASSWORD": "${SMARTUP_PASSWORD}",
        "SMARTUP_FILIAL_CODE": "220.012"
      }
    }
  }
}
```

Проверить — командой `/mcp` внутри сессии.

### OpenAI Codex

В `~/.codex/config.toml`:

```toml
[mcp_servers.smartup]
command = "node"
args = ["/абсолютный/путь/smartup-mcp/server/index.js"]

[mcp_servers.smartup.env]
SMARTUP_LOGIN = "ваш_логин"
SMARTUP_PASSWORD = "ваш_пароль"
SMARTUP_FILIAL_CODE = "220.012"
```

Либо `codex mcp add smartup -- node /абсолютный/путь/smartup-mcp/server/index.js`. Проверить — `codex mcp list`.

### OpenClaw

```bash
openclaw mcp add smartup \
  --command node \
  --arg /абсолютный/путь/smartup-mcp/server/index.js \
  --transport stdio
```

Либо в `openclaw.json`:

```json
{
  "mcp": {
    "servers": {
      "smartup": {
        "command": "node",
        "args": ["/абсолютный/путь/smartup-mcp/server/index.js"],
        "transport": "stdio",
        "enabled": true
      }
    }
  }
}
```

Доступы держите в окружении, с которым запускается OpenClaw, а не в самом конфиге. Проверить — `openclaw mcp doctor smartup --probe`.

### Hermes

В `~/.hermes/config.yaml`:

```yaml
mcp_servers:
  smartup:
    command: "node"
    args: ["/абсолютный/путь/smartup-mcp/server/index.js"]
    env:
      SMARTUP_LOGIN: "${env:SMARTUP_LOGIN}"
      SMARTUP_PASSWORD: "${env:SMARTUP_PASSWORD}"
      SMARTUP_FILIAL_CODE: "220.012"
    enabled: true
```

Секреты — в `~/.hermes/.env`. Проверить — `hermes tools list`.

### Всё остальное

Сервер говорит по MCP через stdio. Команда `node`, единственный аргумент — абсолютный путь к `server/index.js`, доступы в окружении. Больше ни одному MCP-клиенту ничего не нужно.

## Как устроен разговор со SmartUp

Три особенности этого API определяют в коде почти всё, и встречать их впервые на боевом контуре неприятно:

**Всё через POST**, включая чтение. GET-методов нет вовсе.

**Отказ приходит с кодом 200.** Это может быть валидный JSON с `error_code`, обычный русский текст или массив `errors[]` рядом с `successes[]`. «Ответ пришёл» здесь не значит «всё хорошо».

**Две несовместимые формы ответа.** Большинство методов отвечают `{ "<сущность>": [...], "limits": {...} }`, методы `/api/v2/` — `{ "count": "1", "data": [...] }`. И один метод, `product_price$export`, формально `/api/v2/`, но корневой ключ у него всё равно по имени сущности. Коннектор разбирает все три случая.

Даты уходят в формате `дд.мм.гггг`. Инструменты принимают `2026-09-06`, `06.09.2026`, «вчера» или `-7d` и переводят сами.

## Разработка

```bash
npm start                    # запустить сервер на stdio
npx @anthropic-ai/mcpb pack  # собрать smartup.mcpb
```

Сервер — обычные ES-модули, сборка не нужна. `server/smartup.js` — клиент API, проверки и счётчик квот; `server/tools.js` — чтение; `server/reports.js` — вычисляемые сводки; `server/write.js` — всё, что меняет данные; `server/format.js` — как устроены ответы.

Пул-реквесты приветствуются, особенно инструменты для тех частей SmartUp, которые мы не закрыли.
